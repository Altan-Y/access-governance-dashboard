# Security and privacy

This repository is an independent portfolio demonstration built with fictional names, emails and access records.

It intentionally contains:

- no company source code;
- no production database exports;
- no internal hostnames, URLs or certificates;
- no Active Directory or LDAP credentials;
- no real employee or customer data;
- no third-party API keys.

The included authentication is for local demonstration only. It must be replaced with a production identity provider before real-world use.
